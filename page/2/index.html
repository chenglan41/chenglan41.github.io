1.打开安卓手机，进入设置 → 关于手机，连续点击版本号，开启开发者选项；

2.进入开发者选项，开启 USB 调试、USB 网络调试 两项权限；

3.使用 USB 数据线将手机与电脑连接。

七、网页端连接手机

1.查看手机当前的 IP 地址（可在手机 WLAN 详情、路由器后台查看）；

2.打开电脑浏览器，访问地址：http://localhost:5000 或 http://电脑本机IP:5000；

3.在网页输入框填写「手机 IP: 端口」（例：192.168.1.100:5555），点击连接；

4.此时手机会弹出调试授权提示，选择允许即可完成投屏连接。

1.音频问题

设备连接成功后，手机外放会自动关闭，如需收听声音，可搭配耳机使用。

若出现画面卡住、点击无反应等异常，直接断开网页连接，重新发起连接即可，可多次重试。

3.授权弹窗
网页发起连接请求时，手机一定会弹出调试授权窗口，若未弹出，请重新插拔 USB、重新开启 USB 调试。

4.连接失败通用排查

  • 检查 adb devices 是否能识别到手机设备；
  • 关闭电脑防火墙、杀毒软件，避免端口 5000 / 5555 被拦截；
  • 确认手机与电脑处于同一局域网。

逆元

Posted on 2026-03-29 Edited on 2026-08-03 In Coding

接下来，我们来学习如何求解线性同余方程。让我们考虑如何求线性方程ax=b(mob m)。对于实数运算下的方程ax=b，由于a存在倒数，因此很容易求解。如果在mod m的运算下，也有像满足ay=1(mob m)这样的a的倒数存在，方程就可以求解了。我们把这样的y叫做a的逆元，记作a^-1。如果能求解逆元，那么就有x=a^-1*xa=a^-1b，也就可以求出x了。由于方程ax=1(mob m)等价于存在整数k使得ax=1+mk，因此稍作变形之后，可以变为求解满足ax-mk=1的x的问题。这个问题可以用extgcd(扩展欧几里得算法)求解。同时，也可以知道如果gcd(a,m)!=1，那么逆元是不存在的。

如果a和m不互素，那么ax=b(mob m)就等价于
(a/gcd(a,m))x≡b/gcd(a,m)(mob m/gcd(a,m))
从式子中可以看出，当b无法整除gcd(a,m)时，原方程无解。在有解的情况下，我们有
x≡gcd(a/gcd(a,m))^(-1)*(b/gcd(a,m))(mob m/gcd(a,m))
因此，ax=b(mob m)的解为
x≡a(a/gcd(a,m))^(-1)*(b/gcd(a,m))+(m/gcd(a,m))*k(mob m)(0≤k<gcd(a,m))
需要注意的是这里和实数的情况有所不同，有可能有多解，也有可能无解。

输出格式

对于每个字符串，输出一行：

  • 若其为合法括号序列，输出 YES；
  • 否则输出 NO。

输出 #1

输入输出样例 #2

输入 #2

输出 #2

记单串长度记为 $|S|$。测试数据满足 $1 \leq |S| \leq 10^6$，$1 \leq T \leq 2\times 10^5$，同一输入文件内总长度 $\sum |S| \leq 2\times 10^6$，字符串只包含字符 ()[]{}。

比如(((它没有右括号所以也是不符合的，
